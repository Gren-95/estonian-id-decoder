How the code is structured

An Estonian isikukood is 11 digits: G YYMMDD SSS C

PositionMeaning
GCentury & gender: 1/2 = male/female born 1800–1899, 3/4 = 1900–1999, 5/6 = 2000–2099, 7/8 = 2100–2199
YYMMDDDate of birth
SSSSequential number distinguishing people born on the same date
CChecksum digit, computed with a weighted mod-11 algorithm over the first 10 digits

This tool only parses the public, self-describing structure of the code. It does not look anyone up and makes no network requests — check the Network tab if you like.

Runs 100% client-side — no data is transmitted anywhere.

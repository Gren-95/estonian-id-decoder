Excel formulas

Decode a whole column in Excel. Put the codes in one column, paste each formula into the first row of its own column, then fill down. The formulas need Excel 365 or Excel 2021 or later (they use LET and SEQUENCE).

If Excel says "There's a problem with this formula", switch the separator. Excel follows your Windows or macOS region settings, so where the decimal mark is a comma it expects semicolons.

Format the date-of-birth column as a Date. Codes may be stored as numbers or as text. The status check ignores spaces and dashes, but the gender and date formulas expect plain 11-digit codes. Dates before 1900 (codes starting with 1 or 2) still validate, but Excel cannot display them as dates.

How the code is structured

An Estonian isikukood is 11 digits: G YYMMDD SSS C

PositionMeaning
GCentury & gender: 1/2 = male/female born 1800-1899, 3/4 = 1900-1999, 5/6 = 2000-2099, 7/8 = 2100-2199
YYMMDDDate of birth
SSSSerial number that tells apart people born on the same date. Before 2013 it also encoded the hospital of birth
CChecksum digit, computed with a weighted mod-11 algorithm over the first 10 digits

This tool only parses the public, self-describing structure of the code. It does not look anyone up and makes no network requests; check the Network tab if you like.

Runs entirely in your browser. No data is sent anywhere.
